# DOM Manipulation Project # Explore&Go — Activity Hub 🌍 ## 📌 Project Overview Explore&Go is a modern interactive web application built using **HTML5, CSS3, Tailwind CSS, and JavaScript DOM Manipulation**. The website allows users to explore Rwanda-themed activities, interact with dynamic content, manage personalized lists, switch themes, and navigate through image carousels.
